QUICK START:
1. npm install
2. npm run dev
3. Visit: http://localhost:9001/?mobile=1
4. V2 Enhanced is default (tutorial starts)
5. Switch to V1 Classic via ⚙️ button

DEPLOYMENT:
1. grunt build
2. Deploy dest/prod/ to your host
3. Access with ?mobile=1 parameter
4. Both versions ready for production!
