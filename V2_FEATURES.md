## ✨ New Features in V2

### 1. Interactive Onboarding 🎓

**First-time users get a guided tour!**

- Step-by-step walkthrough of all features
- Visual highlights on important elements
- Can skip and replay anytime
- Accessible via **? button** (bottom right)

**What it teaches:**
- Mode switching (Draw/Import)
- Tool drawer usage
- Touch gestures
- Quick actions
- Export workflow

### 2. Quick Actions Menu ⚡

**Floating menu for common tasks**

Access from the **⚡ button** (bottom left)

**Available actions:**
- 🔄 Undo/Redo (with gesture hints)
- 🗑️ Clear Canvas
- ▦ Toggle Grid
- ⊙ Center Canvas
- ⇄ Flip Horizontal
- ⇅ Flip Vertical
- 📋 Duplicate Frame

**Why it's useful:**
- One-tap access to frequent actions
- No need to memorize all gestures
- Great for tablet users
- Shows gesture shortcuts

### 3. Enhanced Gestures 🎨

**Better visual feedback for all touch interactions**

**What's improved:**
- ✨ Visual trails while swiping
- 🎯 Indicator shows gesture type
- 📏 Pinch zoom with circle indicator
- 🔔 Haptic-like feedback
- ⏱️ Smooth animations

**Gestures available:**
- **Swipe Right** → Undo (shows "Undo" indicator)
- **Swipe Left** → Redo (shows "Redo" indicator)
- **Pinch Out** → Zoom In (shows zoom circle)
- **Pinch In** → Zoom Out (shows zoom circle)
- **Long Press** → Color Picker (V1 feature)

### 4. Animation Preview 🎬

**See your animations come to life!**

After auto-chopping sprites, get:
- ▶️ Play/Pause controls
- ⏮️ Previous frame
- ⏭️ Next frame
- 🎚️ FPS slider (1-30 fps)
- 📊 Frame counter

**Use cases:**
- Preview walk cycles
- Check animation smoothness
- Adjust frame timing
- Verify loop points

### 5. Color Palette Management 🎨

**Professional color workflow**

**Recent Colors:**
- Automatically tracks last 12 colors
- Click any color to reuse
- Persists across sessions

**Color Presets:**
- **Game Boy** - Classic 4-color palette
- **NES** - Retro 8-color palette
- **Pastel** - Soft modern colors
- **Neon** - Bright vibrant colors
- **Earth** - Natural tones
- **Fire** - Warm gradient

**Custom:**
- Add current color to history
- Build your own palette
- Quick access to favorites

### 6. Export Preview 💾

**See before you export!**

**Features:**
- 👁️ Live sprite sheet preview
- 📏 Size and frame information
- 🎯 Multiple format buttons
- ✅ Format selection with icons
- 📦 Enhanced metadata

**Export formats:**
- 📋 Sprite Sheet + JSON
- 🎞️ PNG Sequence + JSON
- 🎬 Animated GIF (new!)
- 📄 JSON Metadata Only

### 7. Version Switcher ⚙️

**Easily compare V1 vs V2**

- Tap **⚙️ button** (top right)
- Switch between versions instantly
- Preference saved automatically
- Both versions always available

## 🎯 Detailed Feature Breakdown

### Onboarding System

**Why it matters:**
- First-time users aren't lost
- Learn features gradually
- Can revisit tutorial anytime
- Reduces learning curve

**How it works:**
1. Shows on first launch
2. Highlights each feature with overlay
3. Progress bar shows completion
4. Can skip with confirmation
5. Access anytime via ? button

**Tutorial covers:**

- Tool drawer
- Touch gestures
- Quick actions (V2)
- Export button

### Quick Actions Menu

**When to use:**
- Need to undo multiple times
- Want to flip sprite quickly
- Toggle grid for alignment
- Clear canvas for fresh start
- Center view after zooming

**Keyboard alternative (desktop):**
- Most actions have keyboard shortcuts
- Quick Actions shows these hints
- Great for learning shortcuts

### Enhanced Gesture Feedback

**Visual improvements:**
- Smooth trail follows your finger
- Clear indicators for each gesture
- Color-coded feedback
- Non-intrusive but informative

**Performance:**
- Uses canvas for smooth rendering
- Fades out gracefully
- Doesn't interfere with drawing
- Optimized for mobile devices

### Animation Preview

**Professional workflow:**
1. Import sprite sheet
2. Auto-chop detects frames
3. Preview opens automatically
4. Adjust FPS to match game
5. Verify all frames work
6. Export when satisfied

**Controls explained:**
- **▶️ Play**: Loops animation continuously
- **⏸️ Pause**: Stop on current frame
- **⏮️ Prev**: Go back one frame
- **⏭️ Next**: Advance one frame
- **FPS Slider**: Adjust playback speed

### Color Palette Features

**Workflow improvements:**
- No more re-entering hex codes
- Quick palette swapping
- Recent colors always accessible
- Presets for common styles

**Best for:**
- Pixel art with limited colors
- Maintaining consistent palette
- Quick color experimentation
- Retro/themed sprites

### Export Preview

**Why preview first:**
- Verify frame layout
- Check for empty frames
- Confirm size/dimensions
- Choose right format
- Spot issues before export

**Format recommendations:**
- **Sprite Sheet**: Best for most games
- **PNG Sequence**: Maximum flexibility
- **Animated GIF**: Quick previews
- **JSON Only**: Update metadata

**A:** Yes, same export formats and metadata.

**A:** No, same performance. Visual effects are optimized.

**A:** Yes, switching versions preserves your current work.
