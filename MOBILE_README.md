# 🎮🎨 Piskel Mobile Edition - MIFF Fork

A mobile-first, touch-optimized sprite editor forked from Piskel, designed specifically for **MIFF (Modular Interactive Fiction Framework)** and other modular game platforms.

## 🌟 Overview

This fork transforms Piskel into a streamlined, mobile-friendly sprite creation tool with modular workflow stages perfect for game asset creation. It maintains Piskel's powerful pixel art editing capabilities while adding mobile touch optimization and structured export for game engines.

## ✨ Key Features

### 📱 Mobile-First Design
- **Touch-optimized UI** - All controls are 48px+ for comfortable touch interaction
- **Gesture support** - Swipe for undo/redo, pinch to zoom, long-press for color picker
- **Clean interface** - Hide all toolbars by default, show only canvas
- **Responsive** - Works on phones, tablets, and desktop browsers

### 🎯 Modular Workflow Stages

#### 1️⃣ **Draw or Import Mode**
- **Draw Mode**: Start with a blank canvas and pixel-perfect drawing tools
- **Import Mode**: Upload sprite sheets or images for processing
- Quick mode switching with floating button

#### 2️⃣ **Auto-Chop Pipeline**
- Automatically detect grid sizes (16x16, 32x32, 64x64, etc.)
- Edge detection for sprite boundaries
- Manual grid size input fallback
- Preview all chopped sprites in scrollable tray

#### 3️⃣ **Tag & Place**
- Tag animations with metadata (idle, walk, attack, etc.)
- Categorize assets (character, npc, item, effect, environment, ui)
- Define frame ranges and FPS per animation
- Structured tagging system for engine integration

#### 4️⃣ **Export for Game Engines**
- **PNG Sequence + JSON** - Individual frames with metadata
- **Sprite Sheet + JSON** - Combined sheet with layout info
- **MIFF Bundle** - ZIP with manifest scaffold
- **JSON Only** - Metadata for existing sprites

## 📋 Usage Guide

### Drawing Mode
1. Tap **✏️ Draw** button (top right)
2. Tap drawer handle (bottom) to access tools
3. Select tool (Pen, Eraser, Fill, etc.)
4. Draw on canvas
5. **Gestures:**
   - Swipe right → Undo
   - Swipe left → Redo
   - Pinch → Zoom in/out
   - Long press → Color picker
6. Auto-saves to IndexedDB

### Import Mode
1. Tap **📥 Import** button (top right)
2. Upload or drag-drop sprite sheet
3. Adjust grid size if needed (auto-detected)
4. Review chopped sprites in asset tray
5. Select frames to use
6. Tap "Tag Frames" to add metadata

### Tagging Animations
1. Enter animation name (e.g., "walk")
2. Add tags (comma-separated): `npc, character, element-fire`
3. Set frame range (start-end)
4. Choose category
5. Set FPS
6. Save tag

### Exporting
1. Tap **💾 Export** button (bottom center)
2. Choose export format
3. Name your asset
4. Include manifest for MIFF scaffolding
5. Download files

## 📦 Export Format

### JSON Metadata Structure
```json
{
  "name": "hero-sprite",
  "version": "1.0.0",
  "miff": {
    "compatible": true,
    "created": "2025-11-07T00:00:00.000Z",
    "editor": "Piskel Mobile Edition"
  },
  "sprite": {
    "width": 32,
    "height": 32,
    "frameCount": 24,
    "layerCount": 1,
    "fps": 10
  },
  "animations": [
    {
      "name": "idle",
      "category": "character",
      "tags": ["npc", "character"],
      "frameStart": 0,
      "frameEnd": 3,
      "frameCount": 4,
      "fps": 6
    },
    {
      "name": "walk",
      "category": "character",
      "tags": ["npc", "character", "movement"],
      "frameStart": 4,
      "frameEnd": 11,
      "frameCount": 8,
      "fps": 10
    }
  ],
  "tags": {
    "npc": [],
    "character": [],
    "movement": []
  }
}
```

### Manifest.txt Structure
```
# MIFF Sprite Manifest
# Generated by Piskel Mobile Edition

## Asset Information
Name: hero-sprite
Size: 32x32
Frames: 24
FPS: 10

## Animations

### idle
Category: character
Frames: 0-3 (4 frames)
FPS: 6
Tags: npc, character

### walk
Category: character
Frames: 4-11 (8 frames)
FPS: 10
Tags: npc, character, movement

## Content Folder Structure
```
/content/sprites/hero-sprite/
  ├── spritesheet.png
  ├── metadata.json
  └── manifest.txt
```

## Usage
This sprite is ready for use in MIFF, Godot, GDevelop, or other game engines.
```

## 🏷️ Tag System

### Suggested Tag Categories
- **zone** - Environmental context (forest, dungeon, town)
- **npc** - Non-player character designation
- **animation** - Animation type (idle, walk, attack, death)
- **element** - Elemental affinity (fire, water, earth, air)
- **variant** - Visual variant (red, blue, winter, summer)

### Tag Format
Tags can be:
- Simple: `npc`, `character`, `item`
- Hierarchical: `element-fire`, `zone-forest`, `variant-blue`

## 🎮 Engine Integration

### Godot
```gdscript
# Load metadata
var sprite_data = JSON.parse_file("res://content/sprites/hero-sprite/metadata.json")

# Set up animation
for anim in sprite_data.animations:
    var animation = Animation.new()
    animation.length = anim.frameCount / float(anim.fps)
    # Add sprite frames...
```

### GDevelop
Import sprite sheet and use JSON to configure:
- Animation names
- Frame ranges
- Speed (FPS)

### MIFF
The manifest and JSON are designed for automatic scaffolding:
```bash
miff import sprite content/sprites/hero-sprite
```

## 🛠️ Technical Details

### Architecture
- **Controllers**: `MobileController`, `ToolDrawerController`, `AssetTrayController`, `TaggingController`
- **Services**: `TouchGestureService`, `AutoChopService`, `MIFFExportService`
- **Events**: Extended Piskel event system with mobile-specific events

### Touch Gestures
- **Swipe (horizontal)**: Undo/Redo
- **Pinch**: Zoom in/out
- **Long press**: Color picker
- **Tap**: Tool selection, drawing
- **Drag**: Pan canvas (when zoomed)

### Auto-Detection
1. **Common sizes**: Tries 8x8, 16x16, 24x24, 32x32, 48x48, 64x64
2. **Edge detection**: Looks for transparent lines between sprites
3. **Manual fallback**: User input dialog if detection fails

### Storage
- **Auto-save**: Uses IndexedDB for persistence
- **Backup**: Compatible with Piskel's backup system
- **Export**: Downloads to device (browser-based)
