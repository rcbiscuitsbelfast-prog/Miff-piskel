## ✨ V3 Professional Highlights

### 1. Advanced Layer Management 🎨
- Multiple layers with blend modes
- Opacity control (0-100%)
- Show/hide, lock/unlock
- Visual thumbnails
- 8 blend modes: Normal, Multiply, Screen, Overlay, etc.

### 2. Onion Skinning 🧅
- See previous & next frames (0-5 each)
- Adjustable opacity (10-80%)
- Custom tint colors
- Perfect for smooth animations

### 3. Symmetry Tools ↔️
- Horizontal, Vertical, Quad symmetry
- Radial symmetry (2-16 segments)
- Live guide overlay
- Works with all drawing tools

### 4. Project Templates 📑
- 8 built-in templates
- Custom size support
- Pre-configured dimensions & FPS
- Quick start workflow

### 5. Advanced Export 💎
- Enhanced JSON with layer data
- APNG export (framework ready)
- WebP export (framework ready)
- Professional metadata
